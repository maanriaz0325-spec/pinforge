# PinForge – Product Ideas & Future Enhancements (IDEAS.md)

1. **Pinterest Official API Publishing (v2):** Full OAuth2 integration to publish pins directly to Pinterest Boards with automated scheduling and rich metrics sync.
2. **Pinterest Trends Auto-Sync:** Automated polling of trending Pinterest search queries mapped directly to Niche keyword seeds.
3. **Vision Model Quality Gate:** Run a fast multimodal vision model (e.g. Gemini Flash / Claude Haiku) over generated raw images to detect visual artifacts, spelling defects, or NSFW elements before applying overlays.
4. **Interactive Fabric.js / Konva Canvas Studio:** Full drag-and-drop client canvas editor for moving text elements, stickers, and logos in the Pin detail modal.
5. **Team Workspaces & Role-Based Access Control:** Invite virtual assistants (VAs) or agency clients with restricted board and brand kit permissions.
